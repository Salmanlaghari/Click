# Click Browser — Games

All games in this directory are **original works by TEAM PK AI**, written
specifically for Click Browser. No third-party code, art or audio is used.

## Games

| Game | File | Controls |
|------|------|----------|
| Snake | `snake/index.html` | Swipe on canvas, on-screen D-pad, arrow keys |
| Breakout | `breakout/index.html` | Drag / pointer move to move paddle |
| Memory Match | `memory/index.html` | Tap cards to flip and match pairs |
| Tic-Tac-Toe | `tictactoe/index.html` | Tap a cell; AI plays O (win/block logic) |
| Sky Hopper | `flappy/index.html` | Tap anywhere (or Space) to flap |

## Rules

- Each game is a single self-contained `index.html` (inline CSS + JS).
- 100% offline — zero network requests, zero external resources.
- Touch-first: every game is fully playable on a phone with touch only.
- High scores persist via `localStorage` (per-game keys, e.g. `click_snake_best`).

  third-party game code.
