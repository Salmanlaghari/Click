# Click Browser

Click is an Android browser with four profiles: Simple, Developer, Power and Advance. Every profile uses Android System WebView. Each has a separate WebView data directory for website cookies and cache; Simple, Developer and Power share app-level history, bookmarks and passwords, while Advance also has separate app-level browsing data. Profiles do not impersonate different devices or browsers.

The app includes tabs, private browsing, bookmarks, history, standard downloads, local media playback, a PDF reader, developer inspection tools, ad blocking, HTTPS settings, a password manager and optional AI features. The DevTools console is read-only. Website geolocation requests are denied; Click does not request device-location permission.
